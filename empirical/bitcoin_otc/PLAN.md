# 涟漪场方程 V2 首次真实拟合：Bitcoin OTC 带符号信任网络（分析计划）

2026-11-18。作者：Claude Code。本计划在运行任何拟合之前写定并记录哈希（`PLAN.sha256`）。此前在同一数据上只做过静态符号拓扑分析（`06_EVIDENCE/reports/k_topology_bitcoin_otc_*`），没有做过任何时序分析。同一分析者、同一会话，属于"轻量预注册"，不等于独立预注册。

## 1. 数据

`07_EXPERIMENTS/external_data/snap_signed_bitcoin_otc/soc-sign-bitcoinotc.csv.gz`，SHA-256 `6424ac98…c373`，35592 条评分（SOURCE 给 TARGET 打 −10…+10 分，带 Unix 时间）。

## 2. 观测模型（从事件到涟漪状态）

- 时间按周离散化，第 0 周从第一条评分所在周开始。
- **涟漪状态** `r_i(t)` = 节点 i 在第 t 周**收到的评分之和 / 10**。带符号、不限区间；当周未收到评分为 0（无涟漪）。
- **网络** `G_t`：截至第 t 周（含）每个有序对 j→i 的**最近一次**评分的符号。只用过去与当周的边，不使用 t+1 的信息。

## 3. 模型（预测 r_i(t+1)）

邻居特征（φ 为 tanh 或恒等）：

- `in_pos_i = Σ_{j→i 为正} φ(r_j(t))`，`in_neg_i = Σ_{j→i 为负} φ(r_j(t))`（给 i 打过分的人）
- `out_pos_i`、`out_neg_i`：i 打过分的人，同理

| 模型 | 右端 |
|---|---|
| M0 | 常数 |
| M1 持续 | `c + d·r_i` |
| M2 线性涟漪 | `c + d·r_i + Σ θ_k·特征_k(φ=恒等)` |
| **M3 V2 饱和涟漪** | `c + d·r_i + w₀·tanh r_i + Σ θ_k·特征_k(φ=tanh)` |
| M4 无符号 | 同 M3，但正负边合并（`in_all`、`out_all`） |
| M5 置换对照 | 同 M3，但每周把 r 在节点间随机置换后再算邻居特征（种子 20261118） |

全部为普通最小二乘，样本为所有（节点, 周）对；只有在第 t 周之前已出现过的节点进入当周样本。

## 4. 切分与指标

- 按时间切分：前 70% 的周训练，后 30% 测试。
- 主要指标：测试集均方误差（MSE）。次要：只在 `r_i(t+1) ≠ 0` 的行上的 MSE；预测符号对"下周收到净负评"的 AUC。
- 不确定性：测试周的整周块自助法（1000 次，种子 20261118），给出 MSE 差的 95% 区间。

## 5. 假设

- **H1 网络涟漪有预测力**：M3 的测试 MSE 低于 M1，差的 95% 区间不含 0。
- **H2 饱和优于线性**：M3 低于 M2，区间不含 0。
- **H3 符号有用**：M3 低于 M4，区间不含 0。
- **H4 负边翻转符号**：训练集上 `θ(in_neg)` 与 `θ(in_pos)` 符号相反（结构平衡的动态版本：经由不信任边传来的涟漪改变方向）。
- **H5 结构而非活跃度**：M3 低于 M5，区间不含 0。
- 报告估计的 `K = d + w₀` 及其所属形态（草案 P3），以及 M3 的全部系数。

任何假设不成立都照实报告；不在看过测试结果后增加或修改模型。
