## 0. 与第一次的关系，以及为什么这次不是"干净"的检验

第一次（`PLAN.md`、`REPORT.md`）的主要指标未通过，诊断指出观测模型把"无事件"和"零涟漪"混在一起。本计划据此修改观测模型——**这是看过第一次测试集结果之后的修改**。因此：

- **E-OTC**：在同一份 Bitcoin OTC、同一时间切分上重拟合。测试期已经被看过，结果只能算"重复使用的留出集"，证据力弱于第一次。
- **E-Alpha（确认性检验）**：SNAP 的 Bitcoin Alpha 数据集（另一个平台，格式相同，此前从未在本项目中使用）。规格完全照搬本计划，不调任何参数。**需要负责人批准下载**；未批准前只报告 E-OTC，并明确标注为非确认性。

## 1. 观测模型

时间按周离散化（同第一次）。对每个节点 i、每周 t：

- 事件计数 `c_i(t)` = 第 t 周收到的评分条数；本周评分和 `q_i(t)` = 收到的评分之和 / 10。
- **涟漪状态**（隐状态的观测近似）：`x_i(t) = e^{−1/4} x_i(t−1) + q_i(t)`，即时间常数固定为 4 周的衰减累积。没有事件的周，x 只衰减、不清零。
- **活跃度**：`h_i(t) = e^{−1/4} h_i(t−1) + c_i(t)`；`g_i(t)` 同理但统计 i **给出**的评分条数。
- 时间常数 4 周事先固定，不做调参。

## 2. 两部分模型

预测目标仍是 `q_i(t+1)`（与第一次相同，结果可比）。

**A 部分：下周是否发生事件**。`y = 1[c_i(t+1) ≥ 1]`，逻辑回归，特征：`log1p h_i`、`log1p g_i`、`log1p c_i(t)`、邻居活跃度 `log1p(Σ_{j∈入邻居} h_j)`、`log1p(Σ_{j∈出邻居} h_j)`、`log1p(节点年龄周数)`。不加正则。

**B 部分：发生事件时的涟漪大小与符号**。只在 `y = 1` 的训练行上做最小二乘，预测 `q_i(t+1)`。

| B 模型 | 右端 |
|---|---|
| B1 持续 | `c + d·x_i` |
| B2 线性 | `c + d·x_i + Σ θ·邻居特征(φ = 恒等)` |
| **B3 V2** | `c + d·x_i + w₀·tanh x_i + Σ θ·邻居特征(φ = tanh)` |
| B4 无符号 | 同 B3，正负边合并 |
| B5 置换 | 同 B3，每周把 x 在节点间随机置换后算邻居特征（种子 20261118） |

邻居特征与第一次相同（入正、入负、出正、出负，网络为截至第 t 周每对的最近一次评分符号），只是把 `r_j(t)` 换成 `x_j(t)`。

**合成预测**：`q̂ = P̂(y=1) · μ̂_B`。

## 3. 指标与切分

- 时间切分：前 70% 的周训练，后 30% 测试（E-Alpha 在它自己的周数上同样切分）。
- 主要指标：合成预测在全部测试行上的 MSE。
- 次要：A 部分测试 AUC；B 部分在测试事件行上的 MSE；条件于事件、预测"净差评"的 AUC。
- 不确定性：测试周整周块自助法 1000 次，种子 20261118。

## 4. 假设（E-OTC 与 E-Alpha 各自检验）

- **G1 两部分模型修复观测问题**：两部分 + B3 的合成 MSE 低于第一次的 M1 持续模型（`c + d·r_i`），区间不含 0。
- **G2 涟漪动力学有用**：B3 的事件行 MSE 低于 B1，区间不含 0。
- **G3 饱和优于线性**：B3 低于 B2，区间不含 0。
- **G4 符号有用**：B3 低于 B4，区间不含 0。
- **G5 结构而非活跃度**：B3 低于 B5，区间不含 0。
- **G6 负边翻转符号**：B3 中 θ(入·负) 与 θ(入·正) 符号相反。
- **G7 符号预警**：条件于事件，B3 预测净差评的 AUC 的 95% 自助区间下限 > 0.5。

报告 B3 的 `K = d + w₀`。看过结果后不增加模型、不改特征；任何额外分析标为探索性。
